# Payment operations

Use independent Razorpay test credentials in staging. Configure automatic or explicit capture as approved and the existing signed webhook. Exercise checkout, delayed webhook reconciliation, partial refund, duplicate delivery and late-capture compensation. Compare booking state, provider events and ledger entries.

The system page lists stale orders and unapplied captures. Administrators supply a reason before reconciling an individual order. Reconciliation uses the same provider verification and booking transition code as the webhook. Offline collections and settlements record operator reports.

Marketplace collection and payout to independent turf owners require a provider-approved commercial arrangement. Checkout alone does not authorize marketplace settlement. Keep live payments disabled until merchant activation, controlled live tests, settlement, legal, and finance checks are approved.
